## Support Process

### Before Contacting Support

1. **Check Documentation**
   - Review the main [README.md](../README.md)
   - Check [ENVIRONMENTS.md](terraform/ENVIRONMENTS.md) for environment-specific issues
   - Review AWS service documentation for service-specific questions

2. **Troubleshooting Steps**
   - Verify AWS credentials are configured correctly
   - Check Terraform version compatibility (>= 1.0)
   - Review error messages and logs
   - Check CloudWatch logs for Lambda/Connect issues

3. **Gather Information**
   - Environment (dev/test/prod)
   - Terraform version
   - AWS region
   - Error messages and stack traces
   - Steps to reproduce the issue

### Reporting Issues

When contacting support, please include:

- **Environment**: dev, test, or prod
- **Issue Type**: Deployment, Configuration, Runtime, etc.
- **Error Messages**: Full error output from Terraform or AWS
- **Steps to Reproduce**: What actions led to the issue
- **Expected Behavior**: What should have happened
- **Actual Behavior**: What actually happened
- **Relevant Logs**: CloudWatch logs, Terraform logs, etc.

### Response Times

- **Urgent Production Issues**: Within 4 hours
- **General Support**: Within 1 business day
- **Feature Requests**: Within 2-3 business days
